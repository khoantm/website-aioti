Kết nối với GitHub

Làm một lần trên mỗi máy / điện thoại. Mã khóa chỉ lưu trong trình duyệt này.

  1. Mở trang tạo mã khóa GitHub (đăng nhập nếu được hỏi)
  2. Token name: Quan ly web AIOTI · Expiration: chọn dài nhất
  3. Repository access: Only select repositories → chọn website-aioti
  4. Permissions → Repository permissions → Contents: Read and write
  5. Bấm Generate token, copy mã, dán vào ô dưới

Thêm ảnh công trình

Chọn ngành trước, rồi bấm nút để chụp hoặc chọn ảnh. Ảnh tự nén, không lo nặng.

★ = ảnh đại diện của ngành, hiện ở mục Dịch vụ. Chú thích nên nói chi tiết kỹ thuật — đó là thứ làm khách tin tay nghề.

Thêm video YouTube

Đăng video lên kênh YouTube của AIOTI trước, rồi bấm Chia sẻ → Sao chép đường liên kết và dán vào đây. Nhận cả video thường và Shorts. Chưa có video nào thì mục Video tự ẩn khỏi web.

Chữ tiêu đề mục Video

Có link thì cuối mục hiện dòng "Xem thêm trên kênh YouTube AIOTI". Để trống thì ẩn.
