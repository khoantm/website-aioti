Kết nối với GitHub

Làm một lần trên mỗi máy / điện thoại. Mã khóa chỉ lưu trong trình duyệt này.

  1. Mở trang tạo mã khóa GitHub (đăng nhập nếu được hỏi)
  2. Token name: Quan ly web AIOTI · Expiration: chọn dài nhất
  3. Repository access: Only select repositories → chọn website-aioti
  4. Permissions → Repository permissions → Contents: Read and write
  5. Bấm Generate token, copy mã, dán vào ô dưới

✎ Sửa tiêu đề mục Công trình

Thêm ảnh công trình

Chọn ngành trước, rồi bấm nút để chụp hoặc chọn ảnh. Ảnh tự nén, không lo nặng.

Trên máy tính: kéo ảnh hoặc cả thư mục ảnh thả vào trang · dán ảnh bằng Ctrl+V

★ = ảnh đại diện của ngành, hiện ở mục Dịch vụ. Chú thích nên nói chi tiết kỹ thuật — đó là thứ làm khách tin tay nghề.

✎ Sửa tiêu đề mục Video

Có link thì cuối mục hiện dòng "Xem thêm trên kênh YouTube AIOTI". Để trống thì ẩn.

Thêm video YouTube

Đăng video lên kênh YouTube của AIOTI trước, rồi bấm Chia sẻ → Sao chép đường liên kết và dán vào đây. Nhận cả video thường và Shorts. Chưa có video nào thì mục Video tự ẩn khỏi web.

✎ Sửa tiêu đề mục Bảng giá

Ảnh bảng giá

Tải ảnh bảng giá, catalogue, giá sản phẩm. Ảnh giữ độ nét cao để khách phóng to đọc được. Chưa có ảnh nào thì mục Bảng giá tự ẩn khỏi web.

Trên máy tính: kéo ảnh thả vào trang · dán ảnh bằng Ctrl+V

Mẹo: bọc chữ trong hai dấu sao để in đậm — ví dụ **camera an ninh**.

Tải bản sao lưu về máy

Tải toàn bộ web đang chạy (chữ, ảnh, video, bảng giá, màu sắc, logo, công cụ quản lý) thành một file .zip. Dùng để khôi phục khi web bị lỗi, bị hack, hoặc mất tài khoản GitHub.

Nên tải sau mỗi đợt thay đổi lớn. Cất 1 bản trên máy tính + 1 bản trên NAS / ổ cứng ngoài.

Lịch sử các lần đăng

Mỗi lần bấm Đăng lên web, GitHub tự lưu lại một bản. Bấm Xem để xem lại web lúc đó, Khôi phục để đưa web về bản đó — bản hiện tại vẫn giữ trong lịch sử.

Khôi phục từ file sao lưu

Chọn file .zip đã tải về trước đây (hoặc file "Download ZIP" của GitHub). Toàn bộ web sẽ về đúng như trong file.

Dọn file ảnh không dùng

Tìm các file ảnh còn sót trên GitHub mà website không dùng tới (do upload nhầm hoặc từ bản cũ).
